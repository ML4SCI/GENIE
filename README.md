# GENIE

GENIE is an initiative under [ML4SCI](https://ml4sci.org/) focused on applying machine learning techniques to problems in high-energy particle physics. The repository brings together research projects exploring different machine learning approaches, with the aim of advancing research in the field and providing a collaborative environment for development and experimentation.

## Research Projects

| Project | Research Focus | Approach |
|---|---|---|
| [Deep Graph Anomaly Detection](./Deep_Graph_Anomaly_Detection_Yeyang_Liu/) | Detecting anomalous particle collision events to search for new physics | Graph neural networks and contrastive learning |
| [Graph Representation Learning (2026)](./Graph_Representation_Learning-2026-Rushil_Singha/) | Learning compact representations of particle jets and reconstructing their structure | Graph autoencoders, ChebNet and attention pooling |
| [Graph Representation Learning](./Graph_Representation_Learning_Rushil_Singha/) | Generating realistic particle jets using graph-based generative models | Graph neural networks and latent-space diffusion |
| [Non-local Jet Classification](./Non_local_Jet_Classification_Tanmay_Bakshi/) | Classifying particle jets by modelling long-range dependencies between particles | Non-local graph neural networks |
| [PINNDE (2025)](./Physics_Informed_Neural_Network_Diffusion_Equation_Sijil_Jose/) | Developing fast sampling methods by solving reverse-time diffusion equations | Physics-informed neural networks |
| [PINNDE (2026)](./PINNDE_Sijil_Jose_2026/) | Generating realistic calorimeter showers for fast detector simulation | Physics-informed diffusion models and generative modelling |
| [PINN Flow (2026)](./PINN_Flow_Tina_Shen/) | Simulating calorimeter showers conditioned on incident particle energy | Conditional flow matching |

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ML4SCI/GENIE.git
cd GENIE
```

### 2. Select a project

Browse the research projects above and navigate to the directory of the project you want to work on.

```bash
cd <project-directory>
```

### 3. Set up the environment

Each project has its own dependencies and setup requirements. Refer to its README for instructions on:

- Installing dependencies.
- Configuring the environment.
- Downloading and preparing datasets.
- Setting up hardware and execution requirements.

### 4. Run the project

Follow the project's instructions for training, evaluation or inference.

### 5. Contribute

Contributions to existing projects and new research directions are welcome. Explore the repository's [open issues](https://github.com/ML4SCI/GENIE/issues) to find opportunities to contribute. For substantial changes, open an issue to discuss the proposed work before implementation.
